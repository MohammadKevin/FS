## 📌 Overview
A complete fullstack digital agency solution with an Express.js & Prisma backend API and a Next.js landing page displaying services, client testimonials, and settings.

---

## ✨ Key Features
- Dynamic service portfolio and client testimonial management
- Admin settings controller for site metadata and social links
- Responsive landing page with modern animation aesthetics

---

## 🛠️ Tech Stack
- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Express.js, Prisma ORM, Node.js
- **Database**: MySQL / PostgreSQL

---

## 📁 Project Structure
```text
FS/
├── backend/            # Express.js API (controllers, services, prisma)
└── frontend/           # Next.js Landing Page
```

## 🚀 Getting Started

### Prerequisites
Make sure you have the required runtimes and tools installed on your machine:
- Node.js (v18+ recommended) / Appropriate runtime
- Git

### Installation & Local Setup
```bash
git clone https://github.com/MohammadKevin/FS.git
cd FS
# 1. Setup Backend
cd backend && npm install && npm run dev
# 2. Setup Frontend
cd ../frontend && npm install && npm run dev
```
